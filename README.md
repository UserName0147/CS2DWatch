# CS2D Watch — шутер сверху для Wear OS

Одиночный top-down шутер в духе CS2D: ты на арене, со всех сторон
прибывают волны ботов, нужно продержаться и набрать очки. Полноценный
сетевой мультиплеер как в оригинале — отдельная большая задача, тут
её нет, но архитектура написана так, что её можно добавить позже.

## Как запустить

1. Открой Android Studio → **Open** → выбери папку `CS2DWatch`.
2. Дай Android Studio время на **Gradle Sync** (первый раз может
   попросить установить недостающие компоненты SDK — соглашайся).
   Если попросит создать Gradle Wrapper — тоже соглашайся, он не
   входит в архив специально, чтобы не тащить лишний бинарник.
3. Подключи часы:
   - **Физические часы**: включи на них Bluetooth-отладку
     (Настройки → О часах → 7 раз нажми на номер сборки, затем
     Настройки для разработчиков → отладка по Bluetooth/Wi-Fi),
     подключи через `adb pair` / `adb connect`.
   - **Эмулятор**: Device Manager → создать виртуальные часы Wear OS.
4. Нажми Run ▶ и выбери устройство.

## Управление

- **Левая часть экрана** — джойстик, тяни палец от точки касания,
  чтобы двигаться.
- **Кнопка справа** — стрельба. Прицел автоматический: пока держишь
  кнопку, персонаж бьёт по ближайшему врагу. Отдельный стик для
  прицеливания на таком маленьком экране только мешал бы.
- После смерти — тапни по экрану, чтобы начать заново.

## Структура кода

- `Entities.kt` — данные игрока, врага и пули.
- `Joystick.kt` — виртуальный стик.
- `GameState.kt` — вся игровая логика: движение, ИИ ботов, стрельба,
  столкновения, волны. Не завязана на Android UI — можно тестировать
  отдельно.
- `GameView.kt` — отрисовка на Canvas и игровой цикл (30 кадров/сек)
  через `SurfaceView` + отдельный поток.
- `MainActivity.kt` — точка входа.

## Что стоит добавить дальше, по мере роста проекта

- Стены/укрытия на арене (сейчас чистое поле).
- Разные виды оружия и подбираемые предметы.
- Звуки и вибро-отклик (на часах это особенно приятно).
- Спрайты вместо кружков.
- Если всё-таки захочется настоящий PvP-мультиплеер — начать можно
  с `Nearby Connections API` (Bluetooth/Wi-Fi Direct между двумя
  часами рядом), это на порядок проще, чем выделенный сервер.

## Известные ограничения

- Часть Wear OS часов не поддерживает мультитач — тогда одновременно
  двигаться и стрелять не получится, только по очереди. Это
  аппаратное ограничение, не баг кода.
- Позиции джойстика и кнопки стрельбы подобраны с запасом от края
  под круглый экран. Если у тебя квадратные часы — можно смело
  подвинуть их ближе к углам в `GameView.kt` (`surfaceCreated`).
- Иконку приложения не добавлял (нужен файл), будет системная
  заглушка — при желании подставь свою через
  Android Studio → New → Image Asset.
